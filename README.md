# ComHub - E-Commerce Backend

A production-style E-Commerce Backend built using Java and Spring Boot.

This project is being developed sprint by sprint while following software engineering best practices used in real companies.

---

## 🚀 Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
- Spring Validation
- SpringDoc OpenAPI (Swagger)
